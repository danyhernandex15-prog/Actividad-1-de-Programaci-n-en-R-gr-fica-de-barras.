# Actividad 1: Gráfica de Barras

## Tema

Confianza en instituciones políticas.

## Descripción

Esta actividad consiste en la elaboración de una gráfica de barras utilizando R y la librería ggplot2. Se representan los niveles de confianza de la población en distintas instituciones políticas.

## Instituciones analizadas

* INE
* Congreso
* Gobierno Estatal
* Gobierno Federal
* Partidos Políticos

## Herramientas utilizadas

* R
* RStudio
* ggplot2
